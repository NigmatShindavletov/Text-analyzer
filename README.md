# Text Analyzer

Простое GUI-приложение на Python для анализа текста.

## Возможности

- Подсчет количества строк
- Подсчет количества слов
- Подсчет количества символов
- Подсчет количества предложений
- Учет многоточий при подсчете предложений
- Сохранение отчета в `.txt` файл
- Отображение пути к сохраненному отчету
- Темная тема интерфейса

## Используемые технологии

- Python
- CustomTkinter
- Regex (`re`)

## Запуск

Установите CustomTkinter:

```bash
pip install customtkinter
```

Запустите программу:

python text_analyzer.py

Также можно использовать start.bat или exe файл для быстрого запуска программы.

## Как работает
 
1. Вставьте текст в поле ввода.
2. Нажмите Анализировать.
3. Программа подсчитает строки, слова, символы и предложения.
4. Нажмите Сохранить отчет, чтобы сохранить результат в .txt файл.
5. После сохранения программа покажет путь к созданному файлу.
